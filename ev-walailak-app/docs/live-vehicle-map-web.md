# แผนที่พิกัดรถในเว็บ

หน้าเว็บของบัญชี Supabase อ่านตำแหน่ง EV-01 จาก `my_operations_snapshot` (ผู้ขับเห็นเฉพาะ Session ของตน) และ `admin_operations_snapshot` (Manager/Admin) ทุก 5 วินาทีเมื่อแท็บยังแสดงอยู่ ระบบวาดพิกัด GPS และ Main Geofence/Return Zone เป็นแผนที่พิกัดในหน้าเว็บ โดยไม่ส่งพิกัดไปยังบริการแผนที่ภายนอก

สถานะ “พิกัดจากรถล่าสุด” ใช้เฉพาะเมื่อ Session เป็น Active, หลักฐานจากรถยังมีอายุ, และเวลาของ GPS ไม่เกิน 30 วินาที หากไม่มีพิกัดจะแสดง “รอข้อมูลพิกัดจากรถ”; หากข้อมูลเก่าจะแสดงคำเตือนและเวลาที่รับ GPS ล่าสุด บัญชีทดลองยังใช้แผนที่จำลองเดิม

ขั้นตอนนี้ทำเฉพาะฝั่งเว็บ รถ EV-01 ยังไม่ได้ส่ง GPS จริงเข้า Supabase จึงยังไม่สามารถทดสอบการเคลื่อนที่ของรถจริงหรือยืนยันเวลาแฝงของเครือข่ายได้ แผนที่นี้แสดงพิกัดและขอบเขตเท่านั้น ไม่มีภาพถนน

เมื่อมีพิกัด ผู้ใช้กด “เปิด Street View จากพิกัดนี้” เพื่อเปิด Google Maps ในแท็บใหม่ด้วย `map_action=pano` และ `viewpoint` ตาม GPS ล่าสุด พิกัดจะถูกส่งไป Google เฉพาะเมื่อกดปุ่ม ภาพ Street View เป็นภาพที่เคยถ่ายไว้และอาจไม่มีภาพใกล้พิกัดนั้น บัญชีทดลองมีปุ่มแยกที่ใช้พิกัดตัวอย่างของมหาวิทยาลัย ไม่อ้างว่าเป็นตำแหน่งรถจริง การฝัง Street View ภายในหน้าเว็บต้องมี Maps Embed API key และการตั้งค่า billing จึงยังไม่เปิดใช้
