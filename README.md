# โครงการรถจักรยานยนต์ไฟฟ้าต้นแบบ

Repository นี้รวบรวมเอกสารข้อกำหนดและการส่งต่องานสำหรับโครงการรถจักรยานยนต์ไฟฟ้าต้นแบบพร้อมระบบช่วยเตือนการขับขี่ด้วย AI และระบบติดตามดูแลผ่านเว็บแอป

## เอกสารใน repository

- [คู่มือส่งต่องานฉบับปรับปรุง](EV_Motorcycle_Handoff_2026-10-14_C144_RECONCILED.md) — แผนที่เอกสาร ข้อสรุป และมติข้อกำหนดล่าสุด
- [ข้อกำหนดฉบับเต็ม](EV_Motorcycle_Requirements_FULL_2026-10-14_C144_RECONCILED.txt) — ข้อกำหนดในรูปแบบข้อความ
- [ข้อกำหนดสำหรับอ่านและพิมพ์](EV_Motorcycle_Requirements_2026-10-14_C144_RECONCILED_FIT_TO_PAGE.docx) — เอกสาร Word ฉบับจัดหน้า

## สถานะ

เอกสารเหล่านี้เป็นฐานข้อกำหนดและการออกแบบของโครงการ ไม่ใช่หลักฐานว่าซอฟต์แวร์ ฮาร์ดแวร์ หรือวงจรได้พัฒนา ติดตั้ง หรือผ่านการทดสอบความปลอดภัยแล้ว รายการที่ยังรอการออกแบบ การทดสอบ หรือผล Pilot ให้ยึดตามที่ระบุไว้ในเอกสารส่งต่องาน
